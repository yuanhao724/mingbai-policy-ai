## 指标定义

### Hit@1 / Hit@3

对每个可回答问题，相关片段是包含预期关键词的片段。

- Hit@1：Top1 片段是否相关。
- Hit@3：Top3 中至少一个片段相关。

### MRR

首个相关片段排名的倒数，越接近 1 越好。

### 关键词召回

回答覆盖了多少预期事实关键词。关键词由人工标注，例如材料题的「身份证、户口簿、银行卡」。

### 引用有效率

回答里的 `[n]` 是否都在来源范围内。

### 引用覆盖率

可回答问题的回答是否至少有一个引用。

### 引用支撑率

被引用的片段是否包含预期关键词。它检查的是「引用是否支撑结论」，不是「引用格式是否正确」。

### Groundedness 代理

回答句子和上下文之间的字符 bigram 重合率。它只是代理指标，不等同于人工事实核查。

当前本地模式是抽取式回答，句子直接来自原文，所以这个指标会偏高。上线前需要用在线模型模式做人工抽检。

### 拒答准确率

20 条跨域/近域问题是否明确拒绝猜测。

## Top1 未命中

当前有 14 条 Top1 未命中，但 Top3 全部命中。评测页单独列出这些样例，用于分析排序优化空间。

## 局限

- 100 条仍是小样本，且问题由同一份政策语料构造，不能替代真实用户盲测。
- 关键词标注是人工规则，可能低估语义等价的回答。
- 本地抽取式模式会抬高 Groundedness。
- 延迟只测本地检索和抽取，不含网络和浏览器渲染。
- 延迟会随机器负载波动，单次结果不应当作稳定 SLA。
- 没有真实社区用户参与。

## CI 质量门

`--check` 的阈值：

- Hit@3 >= 85%
- 引用有效率 >= 95%
- 引用覆盖率 >= 90%
- 关键词召回 >= 75%
- Groundedness >= 85%
- 拒答准确率 >= 80%

低于阈值 CI 失败。
