AI 应用案例 · 社区政策场景

明白办事

把政策文件，翻译成一张能照着办的清单。

PythonFastAPISQLitescikit-learnSSEPrometheusDockerVibe Coding
面向社区工作者、老年人和新市民。上传政策，几分钟生成一张明白卡：谁能办、能领什么、要带什么、怎么办、什么时候截止、常见坑，每条结论都能回到原文。

a 做了什么

问题：政策不是没有，是看不懂、跑不完、答不过来。条件藏在术语里，材料清单分散，同一个问题窗口每天要答几十遍。

  • 政策翻译：自动拆出谁能办、待遇标准、所需材料、办理流程、时限和注意事项。
  • 原文可追溯：问答锁定当前政策，每条结论带 [n] 引用，展开即可核对原文。
  • 两种视角：居民版用大白话；工作者版生成可直接转述的回复。
  • 能落地：材料清单可勾选、导出 Markdown、打印；支持大字和浏览器朗读。
选政策 / 上传 → 生成明白卡 → 勾选材料 / 提问 → 导出或转述

c 结果怎么样

12个可追溯片段
0.6-0.8s本地问答响应
128预计节省分钟

按「人工 30 分钟 / 政策、助手 5 分钟」和「人工 6 分钟 / 问答、助手 0.5 分钟」估算。测试环境无外网，使用本地 TF-IDF 兜底；实际效果需社区试点验证。

  • 4 份政策均能抽出 3-7 项材料、3-6 步流程，0 控制台报错。
  • 32 条离线评测：Hit@3 100%，引用有效 100%，拒答 100%，Top1 85.7%；26 个测试通过。
  • 桌面与手机均无横向溢出；上传后 1 秒内完成切块、入库和生成。

b 用了什么工具

Python 3.13FastAPISQLitescikit-learn TF-IDF原生 HTML/CSS/JSSSEChatGPT / Claude Code 式 AI 编程
  1. 拆需求：用 AI 把 JD 和痛点拆成 6 个可验证任务：政策卡、引用、问答、上传、导出、适老化。
  2. 生成骨架：让 AI 生成 FastAPI 分层、SQLite schema、SSE 路由和前端结构。
  3. 审查与调试：检查检索范围、引用映射、中文零命中、SSE 断流，再逐项验证。
  4. 沉淀：把有效提示词、踩坑和测试记录写进文档。

提示词 结构化抽取

角色：你是政策翻译助手。
目标：把政策片段改写成居民能照着办的清单。
约束：只依据片段；每条结论标注 [n]；
涉及金额、年龄、时限时提醒以官方为准。
输出：谁能办 / 要带什么 / 怎么办 / 何时截止 / 常见坑。

技术 面试可讲的点

  • 中文检索用字符 n-gram TF-IDF，离线可跑；零命中回退当前政策全文。
  • 问答锁定 doc_id，片段按原文顺序编号，引用和来源一一对应。
  • SSE 流式输出，模型不可用时自动回退本地检索。
  • 32 条 gold set + 质量门；AI 结果默认待审核，审核动作写审计日志。
